# M2.3 Donor Matching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a request is submitted, LifeLine finds the nearest compatible, eligible potential donors (red-cell ABO/Rh rules, availability, admin verification, donation interval), the donors accept or decline on a "Requests for you" page, and the requester sees the list through `/api/v1`, with a donor's name and mobile number shown only after that donor accepts.

**Architecture:** Same shape as M2.2: the rules live on the models. `BloodRequest::COMPATIBLE_DONORS` holds the compatibility table, `Donor::eligibleFor()` is the eligibility query (built on `Donor::searchable()`), `BloodRequest::matchDonors()` ranks by distance from the hospital and saves `donor_matches` rows, and `DonorMatch::respond()` is the only way to answer (row locks; the first acceptance calls `changeStatus('donor_found')`). One small `App\Support\Distance` class (Haversine, reused by the M2.4 map). One web controller for donors, one API controller for requesters, one plain-JS file. No new packages and no migration: `donor_matches` already has the columns and the UNIQUE (request, donor) index.

**Tech Stack:** PHP 8.2 (XAMPP), Laravel 12, MariaDB 10.4 (XAMPP), Blade, Bootstrap 5.3.3 and Bootstrap Icons 1.11.3 (vendored, DEC-013), plain JavaScript, PHPUnit 11.

**Approved at kickoff (2026-11-14): DEC-015 option A and DEC-016, recorded in `genOS/brain/30_DECISIONS.md`.**

**DEC-015 — How signed-in `/api/v1` routes know the user.** The `api` route group has no session today, so `/api/v1` can only serve public data (tracking).
- **A (recommended): the `web` middleware group on signed-in API routes.** `routes/api.php` gets `Route::middleware(['web', 'auth', 'verified', 'role:...'])`. The browser sends the normal login session cookie; POST/PATCH/DELETE also need the CSRF token (the plain-JS files send it from a `<meta name="csrf-token">` tag when M2.5 adds the first API write). No new package, nothing new to explain at the defense, and it is what DEC-001 already says ("using the normal login session (no Sanctum tokens)"). Public routes (tracking) stay stateless.
- **B: Laravel Sanctum, stateful mode.** Adds the `laravel/sanctum` package, `config/sanctum.php`, a `personal_access_tokens` migration and `auth:sanctum`. The demo host must be listed in `SANCTUM_STATEFUL_DOMAINS` or every API call fails with 401 (a deployment trap while the demo environment is undecided). It only pays off if a native mobile client is added later (DEC-001's Flutter alternative), and Sanctum can be added then. It goes against DEC-001's simplicity rule.
- Result of A in this milestone: one signed-in endpoint, `GET /api/v1/requests/{id}/matches`.

**DEC-016 — M2.3 matching rules (kickoff defaults):**
1. Matching runs when a request is submitted, and again when the requester presses **Find more donors** (while the request is `open` or `donor_found`). Each run adds up to **10** of the nearest eligible donors that this request has not matched yet (`config/lifeline.php` → `match_limit`). No radius: LifeLine serves Butuan City only.
2. Eligible = `Donor::searchable()` (verified, available, sharing location) + blood type compatible with the request (red cells / whole blood, table below) + has approximate coordinates + no donation in the last **3 months** (`config/lifeline.php` → `donation_interval_months`, taken from design B2 "must be 3+ months ago"; the team must confirm it against a cited source before the defense, DEC-008) + not the requester's own donor profile.
3. Until M2.4 captures coordinates, only donors with coordinates (seeded or factory data) can be matched. No fallback by city.
4. Distance = Haversine from the hospital (DEC-014) to the donor's approximate coordinates, shown rounded to whole kilometres ("about 3 km", never below 1) (DEC-004).
5. Donors see their matches on a new **Requests for you** page (home dashboard button with a count). Before answering they see blood type, units, urgency, hospital name and address, distance and time. Each match is answered once: **accept** or **decline**. Answers are refused once the request is fulfilled, cancelled or expired.
6. The first acceptance moves the request from `open` to `donor_found` through `changeStatus()` (history row, `changed_by` = the donor's user, remarks "A donor accepted"). Later acceptances keep `donor_found`. Declines never change the request.
7. Contact after acceptance only (DEC-004): the requester sees an accepted donor's name and mobile number (Call / SMS links); the donor who accepted sees the patient name, the requester's name and mobile number, and the hospital phone. Waiting and declined matches show only blood type, rounded distance and status.
8. No notifications are sent in M2.3; the "notified" match rows are what M2.5 will notify. No map (M2.4).
9. Limits, each with its own counter: matches API 60 per minute per user (`throttle:60,1,matches`), Find more donors 5 per 10 minutes per user (`throttle:5,10,find-donors`).

## Global Constraints

- Keep the code simple: no new Composer or npm packages, no Vite, no `@vite` (DEC-001, DEC-013). The only new JavaScript file is `lifeline/public/js/matches.js`; it builds HTML with `textContent` and `createElement`, never `innerHTML`.
- No new migration. `donor_matches` statuses are `notified`, `accepted`, `declined`; the UNIQUE (`blood_request_id`, `donor_id`) index means a donor is matched at most once per request.
- `status` and `responded_at` are **not** mass-assignable on `DonorMatch`. Create matches only with `BloodRequest::matchDonors()`; answer only with `$donorMatch->respond()`. Change request status only with `$bloodRequest->changeStatus()`.
- Every donor query for matching starts from `Donor::searchable()` (through `Donor::eligibleFor()`), and selects only `id`, `approx_latitude`, `approx_longitude` (DEC-004).
- No API response or page ever contains a donor's coordinates. Distances shown to people are whole kilometres, minimum 1.
- Ownership: request ids are looked up through `$request->user()->bloodRequests()`; match ids through `$request->user()->donor()->firstOrFail()->matches()`. Other people's ids give 404.
- Signed-in `/api/v1` routes use `['web', 'auth', 'verified', 'role:...']` (DEC-015). The public tracking route keeps no session middleware.
- `/api/v1` errors are JSON: `{"message": "..."}`, plus `"errors"` for 422. Tests check `message` with `assertJsonPath`, never `assertExactJson` (`APP_DEBUG=true` adds keys locally).
- Medical disclaimer wording (DEC-007), shown on the Requests for you page and the request page (already there): "LifeLine only suggests potential donors. Final compatibility and eligibility are confirmed by healthcare professionals." Lists say "potential donor", never "compatible donor" or "eligible donor".
- Every form has `@csrf`; PATCH forms also `@method('PATCH')`. Views never use `{!! !!}`.
- Layout sections: `title`, `content`, optional `container_class`. Flash messages: `session('status')` (success), `session('error')` (danger).

```php
    /**
     * The only way to change a status: checks TRANSITIONS and writes request_history
     * in the same transaction. Nothing on this model changes unless the change is allowed.
     */
    public function changeStatus(string $status, ?User $changedBy, ?string $remarks = null): void
    {
        DB::transaction(function () use ($status, $changedBy, $remarks) {
            // Read the saved status under a row lock, so two changes at the same moment cannot both pass.
            $oldStatus = self::whereKey($this->id)->lockForUpdate()->value('status');

            if (! in_array($status, self::TRANSITIONS[$oldStatus] ?? [], true)) {
                throw new InvalidArgumentException("A {$oldStatus} request cannot become {$status}.");
            }

            $this->status = $status;
            $this->save();

            $this->history()->create([
                'changed_by' => $changedBy?->id,
                'old_status' => $oldStatus,
                'new_status' => $status,
                'remarks' => $remarks,
            ]);
        });
    }
```

```php
namespace Tests\Unit;

use App\Models\BloodRequest;

 * Red-cell (whole blood) ABO/Rh compatibility, all 8 x 8 pairs (M2.3 completion criterion).

class BloodCompatibilityTest extends TestCase

    private const DONOR_ORDER = ['O-', 'O+', 'A-', 'A+', 'B-', 'B+', 'AB-', 'AB+'];

    // Row = recipient, column = donor in DONOR_ORDER. 1 = the recipient may receive red cells from that donor.
    private const GRID = [
        'O-' => [1, 0, 0, 0, 0, 0, 0, 0],
        'O+' => [1, 1, 0, 0, 0, 0, 0, 0],
        'A-' => [1, 0, 1, 0, 0, 0, 0, 0],
        'A+' => [1, 1, 1, 1, 0, 0, 0, 0],
        'B-' => [1, 0, 0, 0, 1, 0, 0, 0],
        'B+' => [1, 1, 0, 0, 1, 1, 0, 0],
        'AB-' => [1, 0, 1, 0, 1, 0, 1, 0],
        'AB+' => [1, 1, 1, 1, 1, 1, 1, 1],
    ];

    public static function allPairs(): array
    {
        $pairs = [];

        foreach (self::GRID as $recipient => $row) {
            foreach (self::DONOR_ORDER as $column => $donor) {
                $pairs["{$recipient} receives from {$donor}"] = [$recipient, $donor, $row[$column] === 1];
            }
        }

        return $pairs;
    }

    #[DataProvider('allPairs')]
    public function test_compatibility(string $recipient, string $donor, bool $compatible): void
    {
        $this->assertSame($compatible, in_array($donor, BloodRequest::COMPATIBLE_DONORS[$recipient], true));
    }

    public function test_the_table_covers_exactly_the_eight_blood_types(): void
    {
        $this->assertEqualsCanonicalizing(Donor::BLOOD_TYPES, array_keys(BloodRequest::COMPATIBLE_DONORS));

        foreach (BloodRequest::COMPATIBLE_DONORS as $donorTypes) {
            $this->assertSame([], array_diff($donorTypes, Donor::BLOOD_TYPES));
        }
    }
```

- [ ] **Step 3: Write the failing matching tests** `lifeline/tests/Feature/Matching/MatchDonorsTest.php`

```php
<?php

namespace Tests\Feature\Matching;

use App\Models\BloodRequest;
use App\Models\Donation;
use App\Models\Donor;
use App\Models\Hospital;
use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Tests\TestCase;

/** Rule-based matching: compatible, eligible, nearest first (DEC-007, DEC-016). */
class MatchDonorsTest extends TestCase
{
    use RefreshDatabase;

    private Hospital $hospital;

    protected function setUp(): void
    {
        parent::setUp();
        $this->travelTo('2026-11-14 10:00:00');
        config(['lifeline.donation_interval_months' => 3, 'lifeline.match_limit' => 10]);
        $this->hospital = Hospital::factory()->create(['latitude' => 8.950000, 'longitude' => 125.540000]);
    }

    /** A searchable donor east of the hospital: each 0.01 degree of longitude is about 1.1 km here. */
    private function donor(string $bloodType, float $longitude = 125.55, array $attributes = []): Donor
    {
        return Donor::factory()->create($attributes + [
            'blood_type' => $bloodType,
            'approx_latitude' => 8.95,
            'approx_longitude' => $longitude,
            'verification_status' => 'verified',
            'is_available' => true,
            'location_sharing' => true,
        ]);
    }

    private function request(string $bloodType, array $attributes = []): BloodRequest
    {
        return BloodRequest::factory()->create($attributes + [
            'blood_type' => $bloodType,
            'hospital_id' => $this->hospital->id,
            'status' => 'open',
        ]);
    }

    private function matchedDonorIds(BloodRequest $bloodRequest): array
    {
        return $bloodRequest->matches()->orderBy('distance_km')->pluck('donor_id')->all();
    }

    public function test_matches_compatible_donors_nearest_first(): void
    {
        $farUniversal = $this->donor('O-', 125.57);
        $nearSameType = $this->donor('A+', 125.55);
        $this->donor('B+', 125.55);   // incompatible with A+
        $this->donor('AB+', 125.55);  // incompatible with A+
        $bloodRequest = $this->request('A+');

        $added = $bloodRequest->matchDonors();

        $this->assertSame(2, $added);
        $this->assertSame([$nearSameType->id, $farUniversal->id], $this->matchedDonorIds($bloodRequest));
        $nearest = $bloodRequest->matches()->where('donor_id', $nearSameType->id)->first();
        $this->assertSame('notified', $nearest->status);
        $this->assertEqualsWithDelta(1.10, (float) $nearest->distance_km, 0.01);
    }

    public function test_only_searchable_donors_with_coordinates_are_matched(): void
    {
        $eligible = $this->donor('O+');
        $this->donor('O+', 125.55, ['is_available' => false]);
        $this->donor('O+', 125.55, ['verification_status' => 'pending']);
        $this->donor('O+', 125.55, ['verification_status' => 'rejected']);
        $this->donor('O+', 125.55, ['location_sharing' => false]);
        $this->donor('O+', 125.55, ['approx_latitude' => null, 'approx_longitude' => null]);
        $bloodRequest = $this->request('O+');

        $bloodRequest->matchDonors();

        $this->assertSame([$eligible->id], $this->matchedDonorIds($bloodRequest));
    }

    public function test_donors_who_gave_blood_within_the_interval_are_not_matched(): void
    {
        $onTheDay = $this->donor('O+', 125.55);
        Donation::create(['donor_id' => $onTheDay->id, 'donated_on' => '2026-08-14', 'is_self_reported' => true]);
        $tooRecent = $this->donor('O+', 125.56);
        Donation::create(['donor_id' => $tooRecent->id, 'donated_on' => '2026-08-15', 'is_self_reported' => true]);
        $bloodRequest = $this->request('O+');

        $bloodRequest->matchDonors();

        // Exactly 3 months ago (2026-08-14) is allowed; one day later is not.
        $this->assertSame([$onTheDay->id], $this->matchedDonorIds($bloodRequest));
    }

    public function test_the_donation_interval_comes_from_config(): void
    {
        config(['lifeline.donation_interval_months' => 6]);
        $donor = $this->donor('O+');
        Donation::create(['donor_id' => $donor->id, 'donated_on' => '2026-08-14', 'is_self_reported' => true]);
        $bloodRequest = $this->request('O+');

        $this->assertSame(0, $bloodRequest->matchDonors());
    }

    public function test_a_donor_is_never_matched_to_their_own_request(): void
    {
        $requesterDonor = $this->donor('O+');
        $other = $this->donor('O+', 125.56);
        $bloodRequest = $this->request('O+', ['requester_id' => $requesterDonor->user_id]);

        $bloodRequest->matchDonors();

        $this->assertSame([$other->id], $this->matchedDonorIds($bloodRequest));
    }

    public function test_only_the_nearest_donors_up_to_the_limit_are_matched(): void
    {
        config(['lifeline.match_limit' => 2]);
        $first = $this->donor('O-', 125.55);
        $second = $this->donor('O-', 125.56);
        $this->donor('O-', 125.57);
        $bloodRequest = $this->request('O-');

        $this->assertSame(2, $bloodRequest->matchDonors());
        $this->assertSame([$first->id, $second->id], $this->matchedDonorIds($bloodRequest));
    }

    public function test_running_again_adds_only_donors_not_matched_yet(): void
    {
        $first = $this->donor('B+');
        $bloodRequest = $this->request('B+');
        $this->assertSame(1, $bloodRequest->matchDonors());

        $newcomer = $this->donor('B-', 125.56);

        $this->assertSame(1, $bloodRequest->matchDonors());
        $this->assertSame(0, $bloodRequest->matchDonors());
        $this->assertSame([$first->id, $newcomer->id], $this->matchedDonorIds($bloodRequest));
    }

    public function test_closed_requests_are_not_matched(): void
    {
        $this->donor('O+');

        foreach (['fulfilled', 'cancelled', 'expired'] as $status) {
            $bloodRequest = $this->request('O+', ['status' => $status]);
            $this->assertSame(0, $bloodRequest->matchDonors(), $status);
            $this->assertSame(0, $bloodRequest->matches()->count(), $status);
        }
    }

    public function test_a_request_with_a_donor_found_still_gets_more_matches(): void
    {
        $donor = $this->donor('AB+');
        $bloodRequest = $this->request('AB+', ['status' => 'donor_found']);

        $bloodRequest->matchDonors();

        $this->assertSame([$donor->id], $this->matchedDonorIds($bloodRequest));
    }
}
```

```php
<?php

namespace App\Support;

/** Straight-line distance on the Earth's surface (Haversine formula). Used by matching (M2.3) and the map (M2.4). */
final class Distance
{
    private const EARTH_RADIUS_KM = 6371;

    public static function km(float $lat1, float $lon1, float $lat2, float $lon2): float
    {
        $latDelta = deg2rad($lat2 - $lat1);
        $lonDelta = deg2rad($lon2 - $lon1);

        $a = sin($latDelta / 2) ** 2
            + cos(deg2rad($lat1)) * cos(deg2rad($lat2)) * sin($lonDelta / 2) ** 2;

        return 2 * self::EARTH_RADIUS_KM * asin(min(1, sqrt($a)));
    }
}
```

```php
    /**
     * Rule-based matching (DEC-016): adds a "notified" match for each of the nearest eligible donors
     * this request has not matched yet, ranked by distance from the hospital (DEC-014).
     * Returns how many matches were added. Closed requests are never matched.
     */
    public function matchDonors(): int
    {
        if (! in_array($this->status, self::LOOKING_FOR_DONORS, true)) {
            return 0;
        }

        $hospital = $this->hospital;

        // Only the columns ranking needs (DEC-004).
        $nearest = Donor::eligibleFor($this)
            ->get(['id', 'approx_latitude', 'approx_longitude'])
            ->map(fn (Donor $donor) => [
                'donor_id' => $donor->id,
                'distance_km' => round(Distance::km(
                    (float) $hospital->latitude,
                    (float) $hospital->longitude,
                    (float) $donor->approx_latitude,
                    (float) $donor->approx_longitude,
                ), 2),
            ])
            ->sortBy('distance_km')
            ->take(config('lifeline.match_limit'));

        $added = 0;

        foreach ($nearest as $candidate) {
            // The UNIQUE (request, donor) index is the final guard if two runs overlap.
            $match = $this->matches()->firstOrCreate(
                ['donor_id' => $candidate['donor_id']],
                ['distance_km' => $candidate['distance_km']]
            );
            $added += $match->wasRecentlyCreated ? 1 : 0;
        }

        return $added;
    }
```

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Support\Facades\DB;
use InvalidArgumentException;

class DonorMatch extends Model
{
    public const ANSWERS = ['accepted', 'declined'];

    public const STATUS_LABELS = [
        'notified' => 'Waiting for reply',
        'accepted' => 'Accepted',
        'declined' => 'Declined',
    ];

    // status and responded_at change only through respond().
    protected $fillable = ['blood_request_id', 'donor_id', 'distance_km'];

    protected function casts(): array
    {
        return [
            'distance_km' => 'decimal:2',
            'responded_at' => 'datetime',
        ];
    }

    /**
     * The donor's one-time answer (DEC-016). The first acceptance moves the request from open to
     * donor_found through changeStatus(), which writes the history row. Throws
     * InvalidArgumentException (with a message for the donor) when the answer is not allowed.
     */
    public function respond(string $answer): void
    {
        if (! in_array($answer, self::ANSWERS, true)) {
            throw new InvalidArgumentException('Unknown answer.');
        }

        DB::transaction(function () use ($answer) {
            // Lock the request first, then this match (always in this order), so a cancel or a
            // second click cannot slip in between the checks and the save.
            $requestStatus = BloodRequest::whereKey($this->blood_request_id)->lockForUpdate()->value('status');
            $matchStatus = self::whereKey($this->id)->lockForUpdate()->value('status');

            if ($matchStatus !== 'notified') {
                throw new InvalidArgumentException('You already answered this request.');
            }

            if (! in_array($requestStatus, BloodRequest::LOOKING_FOR_DONORS, true)) {
                throw new InvalidArgumentException('This request is no longer looking for donors.');
            }

            $this->status = $answer;
            $this->responded_at = now();
            $this->save();

            if ($answer === 'accepted' && $requestStatus === 'open') {
                $this->bloodRequest->changeStatus('donor_found', $this->donor->user, 'A donor accepted');
            }
        });
    }

    public function bloodRequest(): BelongsTo
    {
        return $this->belongsTo(BloodRequest::class);
    }

    public function donor(): BelongsTo
    {
        return $this->belongsTo(Donor::class);
    }
}
```

```php
namespace App\Http\Controllers;

use App\Models\DonorMatch;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Validation\Rule;
use Illuminate\View\View;
use InvalidArgumentException;

/** "Requests for you": the signed-in donor's matches and their accept / decline answers. */
class DonorMatchController extends Controller
{
    public function index(Request $request): View
    {
        $donor = $request->user()->donor()->firstOrFail();

        return view('matches.index', [
            'matches' => $donor->matches()
                ->with(['bloodRequest.hospital', 'bloodRequest.requester'])
                ->orderByDesc('id')
                ->get(),
        ]);
    }

    public function update(Request $request, int $donorMatch): RedirectResponse
    {
        // Ownership first, so other donors' match ids give 404 whatever the input.
        $match = $request->user()->donor()->firstOrFail()->matches()->findOrFail($donorMatch);

        $answer = $request->validate([
            'answer' => ['required', Rule::in(DonorMatch::ANSWERS)],
        ])['answer'];

        try {
            $match->respond($answer);
        } catch (InvalidArgumentException $exception) {
            return back()->with('error', $exception->getMessage());
        }

        return redirect()->route('matches.index')->with('status', $answer === 'accepted'
            ? 'Thank you! The requester can now see your name and mobile number.'
            : 'You declined this request.');
    }
```

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Models\DonorMatch;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;

/**
 * The requester's potential donors for one of their own requests, nearest first. Used by the
 * request page (public/js/matches.js). Never returns coordinates; name and mobile number only
 * for donors who accepted (DEC-004). Signed in through the login session (DEC-015).
 */
class RequestMatchesController extends Controller
{
    public function __invoke(Request $request, int $bloodRequest): JsonResponse
    {
        // Looked up through the user's own requests, so other people's ids give 404.
        $record = $request->user()->bloodRequests()->findOrFail($bloodRequest);

        $matches = $record->matches()
            ->with(['donor:id,user_id,blood_type', 'donor.user:id,first_name,last_name,mobile_number'])
            ->orderBy('distance_km')
            ->get();

        return response()->json(['data' => $matches->map(fn (DonorMatch $match) => [
            'status' => $match->status,
            'status_label' => DonorMatch::STATUS_LABELS[$match->status],
            'blood_type' => $match->donor->blood_type,
            'distance_km' => max(1, (int) round((float) $match->distance_km)),
            'donor' => $match->status === 'accepted' ? [
                'name' => $match->donor->user->first_name.' '.$match->donor->user->last_name,
                'mobile_number' => $match->donor->user->mobile_number,
            ] : null,
        ])->all()]);
    }
}
```

```php
    public function findDonors(Request $request, int $bloodRequest): RedirectResponse
    {
        $record = $request->user()->bloodRequests()->findOrFail($bloodRequest);

        if (! in_array($record->status, BloodRequest::LOOKING_FOR_DONORS, true)) {
            return back()->with('error', 'This request is no longer looking for donors.');
        }

        $added = $record->matchDonors();

        return redirect()->route('requests.show', $record->id)->with('status', $added > 0
            ? "Found {$added} more potential donor(s)."
            : 'No new potential donors right now. Try again later.');
    }
```

```js
// Request page: lists potential donors from GET /api/v1/requests/{id}/matches.
// The browser sends the login session cookie (DEC-015). Text from the API is set with textContent only.
(function () {
    const list = document.getElementById('matches');
    if (!list) return;

    const BADGES = {
        notified: 'text-bg-warning',
        accepted: 'text-bg-success',
        declined: 'text-bg-secondary',
    };

    function element(tag, className, text) {
        const node = document.createElement(tag);
        if (className) node.className = className;
        if (text !== undefined) node.textContent = text;
        return node;
    }

    function showMessage(text, type) {
        list.replaceChildren(element('div', 'alert alert-' + type + ' small mb-0', text));
    }

    function contactLink(scheme, mobileNumber, icon, label) {
        const link = element('a', 'btn btn-sm btn-outline-success');
        link.href = scheme + ':' + encodeURIComponent(mobileNumber);
        const iconNode = element('i', 'bi ' + icon);
        iconNode.setAttribute('aria-hidden', 'true');
        link.append(iconNode, document.createTextNode(' ' + label));
        return link;
    }

    function showMatches(matches) {
        if (matches.length === 0) {
            showMessage('No potential donors found yet. Use "Find more donors" later.', 'secondary');
            return;
        }

        const group = element('ul', 'list-group shadow-sm');
        matches.forEach((match) => {
            const item = element('li', 'list-group-item');
            const header = element('div', 'd-flex justify-content-between align-items-center gap-2');
            header.append(
                element('span', 'fw-semibold', 'Potential donor · ' + match.blood_type + ' · about ' + match.distance_km + ' km'),
                element('span', 'badge ' + (BADGES[match.status] || 'text-bg-secondary'), match.status_label)
            );
            item.append(header);

            if (match.donor) {
                const contact = element('div', 'mt-2 d-flex flex-wrap align-items-center gap-2');
                contact.append(
                    element('span', 'small', match.donor.name + ' · ' + match.donor.mobile_number),
                    contactLink('tel', match.donor.mobile_number, 'bi-telephone', 'Call'),
                    contactLink('sms', match.donor.mobile_number, 'bi-chat-dots', 'SMS')
                );
                item.append(contact);
            }

            group.append(item);
        });
        list.replaceChildren(group);
    }

    fetch(list.dataset.api, { headers: { Accept: 'application/json' } })
        .then((response) => (response.ok ? response.json() : Promise.reject(response)))
        .then((body) => showMatches(body.data))
        .catch(() => showMessage('Could not load potential donors. Refresh the page to try again.', 'danger'));
})();
```
