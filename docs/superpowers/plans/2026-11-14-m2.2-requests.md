# M2.2 Blood Requests, Reference Numbers & Tracking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-in donor or requester submits an emergency blood request (design D1), gets a unique reference number on the request sent screen (D2), follows its status history, cancels it or marks it fulfilled, and anyone can track it by reference number through the first `/api/v1` endpoint.

**Architecture:** Plain Laravel 12 controllers and Blade views on the existing `lifeline/` app. All status rules live on the `BloodRequest` model: `BloodRequest::submit()` is the only way to create a request (unique reference with retry, first history row), and `changeStatus()` is the only way to change a status (allowed-transition check, row lock, history row). One web controller (`BloodRequestController`), one API controller (`Api\TrackRequestController`), one small plain-JS file for the tracking page. No new packages.

**Tech Stack:** PHP 8.2 (XAMPP), Laravel 12.72, MariaDB 10.4 (XAMPP), Blade, Bootstrap 5.3.3 and Bootstrap Icons 1.11.3 (vendored, DEC-013), plain JavaScript, PHPUnit 11.

**Approved at kickoff (2026-11-14), recorded as DEC-014:**
- Donors and requesters with a verified email may submit requests. Admins may not. A donor does not need admin verification to ask for blood.
- The request location is the selected hospital (hospitals already store coordinates). No new location column. M2.3 ranks donors by distance from the hospital.
- Status changes in M2.2: the requester may cancel or mark fulfilled (from `open` or `donor_found`). `donor_found` is set by M2.3 when a donor accepts. Automatic expiry is not built; `expired` is set by the admin status override in M2.6.
- Public tracking shows reference, status, urgency, blood type, hospital name, submitted and updated times, and the status history (status and time only). Never the patient name, units, notes, remarks, requester or contact details. Limited to 30 lookups per minute per IP.
- The tracking page uses the API (plain-JS `fetch` to `GET /api/v1/requests/track/{reference}`): 404 for an unknown reference, 422 for a malformed one.
- Submitting a request is limited to 5 per 10 minutes per user. No cap on open requests.
- Each new rate limit has its own counter (`throttle:max,minutes,prefix`). Laravel's plain `throttle:x,y` keys only by user id (or guest IP), so without a prefix the limits on different routes share one counter.

## Global Constraints

- Keep the code simple: no new Composer or npm packages, no Vite, no `@vite` (DEC-001, DEC-013). The only new JavaScript is `lifeline/public/js/track.js`, plus inline `onsubmit="return confirm(...)"` on the cancel and fulfil forms.
- `reference_number`, `requester_id` and `status` are **not** mass-assignable on `BloodRequest`. Create requests only with `BloodRequest::submit()`; change status only with `$bloodRequest->changeStatus()`. Factories run unguarded, so tests and seeders may still set them.
- Every status change writes a `request_history` row in the same transaction (roadmap completion criterion).
- Request routes act only on the signed-in user's own requests: an id in a URL is looked up through `$request->user()->bloodRequests()`, so other people's requests return 404.
- Reference format `LL-YYMMDD-XXXXXX`, suffix alphabet `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (no I, O, 0, 1). Validation regex: `/^LL-\d{6}-[A-HJ-NP-Z2-9]{6}$/`, after `strtoupper(trim())`.
- Blood types: `Donor::BLOOD_TYPES`. Urgency: `critical`, `urgent`. Units: integer 1–10 (DEC-010).
- Status labels (shown to users): `open` "Looking for donors", `donor_found` "Donor found", `fulfilled` "Fulfilled", `cancelled` "Cancelled", `expired` "Expired" (`BloodRequest::STATUS_LABELS`).
- Medical disclaimer wording (DEC-007): "LifeLine only suggests potential donors. Final compatibility and eligibility are confirmed by healthcare professionals." It appears on the SOS form and the request page.
- `/api/v1` errors are always JSON: `{"message": "..."}`, plus `"errors"` for 422 (Laravel's built-in format, forced for `api/*` in `bootstrap/app.php`). Tests check `message` with `assertJsonPath`, not `assertExactJson`, because `APP_DEBUG=true` adds debug keys locally.
- Every form has `@csrf`; PATCH forms also use `@method('PATCH')`. Views never use `{!! !!}`. `track.js` builds the result with `textContent`, never `innerHTML`.
- Layout sections: `title`, `content`, optional `container_class`. Flash messages: `session('status')` (success), `session('error')` (danger). Field errors inline with `@error`.
- Bottom-nav route names: `home`, `map`, `requests.create`, `alerts.index`, `profile.show`. This milestone creates `requests.create`, so the SOS tab appears.

```php
    /**
     * The only way to create a request: unique reference number (DEC-006), status open,
     * and the first request_history row, saved together.
     */
    public static function submit(User $requester, array $details, ?callable $generateReference = null): self
    {
        $generateReference ??= fn (): string => self::generateReferenceNumber();

        for ($attempt = 1; $attempt <= self::REFERENCE_ATTEMPTS; $attempt++) {
            $reference = $generateReference();

            // Check first (DEC-006); the UNIQUE index still catches a request saved in between.
            if (self::where('reference_number', $reference)->exists()) {
                continue;
            }

            try {
                return DB::transaction(function () use ($requester, $details, $reference) {
                    $bloodRequest = new self($details);
                    $bloodRequest->reference_number = $reference;
                    $bloodRequest->requester_id = $requester->id;
                    $bloodRequest->status = 'open';
                    $bloodRequest->save();

                    $bloodRequest->history()->create([
                        'changed_by' => $requester->id,
                        'old_status' => null,
                        'new_status' => 'open',
                        'remarks' => 'Request submitted',
                    ]);

                    return $bloodRequest;
                });
            } catch (UniqueConstraintViolationException) {
                // Another request took this reference after the check. Try a new one.
            }
        }

        throw new RuntimeException('Could not generate a unique reference number. Please try again.');
    }

    public function canChangeTo(string $status): bool
    {
        return in_array($status, self::TRANSITIONS[$this->status] ?? [], true);
    }

    /**
     * The only way to change a status: checks TRANSITIONS and writes request_history
     * in the same transaction.
     */
    public function changeStatus(string $status, ?User $changedBy, ?string $remarks = null): void
    {
        DB::transaction(function () use ($status, $changedBy, $remarks) {
            // Re-read the status under a row lock, so two changes at the same moment cannot both pass.
            $this->status = self::whereKey($this->id)->lockForUpdate()->value('status');

            if (! $this->canChangeTo($status)) {
                throw new InvalidArgumentException("A {$this->status} request cannot become {$status}.");
            }

            $oldStatus = $this->status;
            $this->status = $status;
            $this->save();

            $this->history()->create([
                'changed_by' => $changedBy?->id,
                'old_status' => $oldStatus,
                'new_status' => $status,
                'remarks' => $remarks,
            ]);
        });
    }
```

```php
<?php

namespace App\Http\Controllers;

use App\Models\BloodRequest;
use App\Models\Donor;
use App\Models\Hospital;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Validation\Rule;
use Illuminate\View\View;

/** Emergency blood requests made by a signed-in donor or requester (design D1, D2). */
class BloodRequestController extends Controller
{
    public function create(): View
    {
        return view('requests.create', [
            'hospitals' => Hospital::orderBy('name')->get(['id', 'name']),
            'bloodTypes' => Donor::BLOOD_TYPES,
        ]);
    }

    public function store(Request $request): RedirectResponse
    {
        $details = $request->validate([
            'patient_name' => ['required', 'string', 'max:150'],
            'blood_type' => ['required', Rule::in(Donor::BLOOD_TYPES)],
            'units' => ['required', 'integer', 'between:1,10'],
            'urgency' => ['required', Rule::in(['critical', 'urgent'])],
            'hospital_id' => ['required', 'integer', 'exists:hospitals,id'],
            'notes' => ['nullable', 'string', 'max:500'],
        ]);

        $bloodRequest = BloodRequest::submit($request->user(), $details);

        return redirect()->route('requests.show', $bloodRequest->id)->with('submitted', true);
    }

    public function show(Request $request, int $bloodRequest): View
    {
        // Looked up through the user's own requests, so other people's ids give 404.
        $record = $request->user()->bloodRequests()
            ->with(['hospital', 'history' => fn ($query) => $query->orderBy('id')])
            ->findOrFail($bloodRequest);

        return view('requests.show', ['bloodRequest' => $record]);
    }
}
```

```php
    /** The requester may cancel a request or mark it fulfilled. Other statuses come from M2.3 and M2.6. */
    public function updateStatus(Request $request, int $bloodRequest): RedirectResponse
    {
        // Ownership first, so other people's ids give 404 whatever the input.
        $record = $request->user()->bloodRequests()->findOrFail($bloodRequest);

        $status = $request->validate([
            'status' => ['required', Rule::in(['cancelled', 'fulfilled'])],
        ])['status'];

        try {
            $record->changeStatus(
                $status,
                $request->user(),
                $status === 'cancelled' ? 'Cancelled by requester' : 'Marked fulfilled by requester'
            );
        } catch (InvalidArgumentException) {
            return back()->with('error', 'This request can no longer be changed.');
        }

        return redirect()->route('requests.show', $record->id)->with('status', $status === 'cancelled'
            ? 'Your request was cancelled.'
            : 'Your request was marked fulfilled.');
    }
```

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Models\BloodRequest;
use Illuminate\Http\JsonResponse;
use Illuminate\Support\Facades\Validator;

/**
 * Public tracking by reference number (DEC-006, DEC-014). Shows the status only: never the
 * patient name, units, notes, remarks, requester or contact details. Used by the /track page.
 */
class TrackRequestController extends Controller
{
    public function __invoke(string $reference): JsonResponse
    {
        $reference = strtoupper(trim($reference));

        Validator::make(
            ['reference' => $reference],
            ['reference' => ['required', 'string', 'regex:/^LL-\d{6}-[A-HJ-NP-Z2-9]{6}$/']],
            ['reference.regex' => 'The reference number must look like LL-261114-ABC234.']
        )->validate();

        $bloodRequest = BloodRequest::with(['hospital:id,name', 'history' => fn ($query) => $query->orderBy('id')])
            ->where('reference_number', $reference)
            ->first();

        abort_if($bloodRequest === null, 404, 'No request found with that reference number.');

        return response()->json(['data' => [
            'reference_number' => $bloodRequest->reference_number,
            'status' => $bloodRequest->status,
            'status_label' => BloodRequest::STATUS_LABELS[$bloodRequest->status],
            'urgency' => $bloodRequest->urgency,
            'blood_type' => $bloodRequest->blood_type,
            'hospital' => $bloodRequest->hospital->name,
            'submitted_at' => $bloodRequest->created_at->toIso8601String(),
            'updated_at' => $bloodRequest->updated_at->toIso8601String(),
            'history' => $bloodRequest->history->map(fn ($entry) => [
                'status' => $entry->new_status,
                'status_label' => BloodRequest::STATUS_LABELS[$entry->new_status],
                'at' => $entry->created_at->toIso8601String(),
            ])->all(),
        ]]);
    }
}
```

```js
// Track page: looks up a request with GET /api/v1/requests/track/{reference} and shows the result.
// Text from the API is set with textContent only.
(function () {
    const form = document.getElementById('track-form');
    const input = document.getElementById('reference');
    const result = document.getElementById('track-result');

    const BADGES = {
        open: 'text-bg-warning',
        donor_found: 'text-bg-info',
        fulfilled: 'text-bg-success',
        cancelled: 'text-bg-secondary',
        expired: 'text-bg-secondary',
    };

    function element(tag, className, text) {
        const node = document.createElement(tag);
        if (className) node.className = className;
        if (text !== undefined) node.textContent = text;
        return node;
    }

    function formatTime(iso) {
        return new Date(iso).toLocaleString('en-PH', { dateStyle: 'medium', timeStyle: 'short', timeZone: 'Asia/Manila' });
    }

    function showMessage(text, type) {
        result.replaceChildren(element('div', 'alert alert-' + type, text));
    }

    function showRequest(data) {
        const header = element('div', 'd-flex justify-content-between align-items-start gap-2 mb-3');
        header.append(
            element('span', 'fw-bold font-monospace', data.reference_number),
            element('span', 'badge ' + (BADGES[data.status] || 'text-bg-secondary'), data.status_label)
        );

        const details = element('dl', 'row small');
        [
            ['Blood type', data.blood_type],
            ['Urgency', data.urgency.charAt(0).toUpperCase() + data.urgency.slice(1)],
            ['Hospital', data.hospital],
            ['Submitted', formatTime(data.submitted_at)],
            ['Last update', formatTime(data.updated_at)],
        ].forEach(([label, value]) => details.append(element('dt', 'col-5', label), element('dd', 'col-7', value)));

        const timeline = element('ol', 'list-group list-group-numbered');
        data.history.forEach((entry) => {
            const item = element('li', 'list-group-item small');
            item.append(element('span', 'fw-semibold', entry.status_label), document.createTextNode(' · ' + formatTime(entry.at)));
            timeline.append(item);
        });

        const body = element('div', 'card-body');
        body.append(header, details, element('h2', 'h6 fw-bold', 'Status history'), timeline);
        const card = element('div', 'card shadow-sm');
        card.append(body);
        result.replaceChildren(card);
    }

    function track(reference) {
        showMessage('Looking up ' + reference + '…', 'light');

        fetch(form.dataset.api + '/' + encodeURIComponent(reference), { headers: { Accept: 'application/json' } })
            .then((response) => response.json().catch(() => ({})).then((body) => ({ status: response.status, body })))
            .then(({ status, body }) => {
                if (status === 200) return showRequest(body.data);
                if (status === 404) return showMessage('No request found with that reference number. Check it and try again.', 'warning');
                if (status === 422) return showMessage('That is not a LifeLine reference number. It looks like LL-261114-ABC234.', 'warning');
                if (status === 429) return showMessage('Too many lookups. Please wait a minute and try again.', 'warning');
                showMessage('Something went wrong. Please try again.', 'danger');
            })
            .catch(() => showMessage('Could not reach LifeLine. Check your connection and try again.', 'danger'));
    }

    form.addEventListener('submit', (event) => {
        event.preventDefault();
        const reference = input.value.trim().toUpperCase();
        history.replaceState(null, '', '?reference=' + encodeURIComponent(reference));
        track(reference);
    });

    // /track?reference=... (linked from the request page) looks the request up right away.
    const fromUrl = new URLSearchParams(location.search).get('reference');
    if (fromUrl) {
        input.value = fromUrl.trim().toUpperCase();
        if (input.checkValidity()) track(input.value);
        else form.reportValidity();
    }
})();
```
