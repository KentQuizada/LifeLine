# LifeLine Mini Thesis: Source Matrix

Citation style: **APA 7th edition** (team decision, 2026-11-17).
Rule: only sources that were located and checked are cited (DEC-008). All checks were done on **2026-11-17**.

**Status values**

- **Verified**: the source was opened (publisher page, DOI record, official site or full text), and the claim we cite was read in it.
- **Partly verified**: the source exists and its details match, but part of what we cite could not be read in full (for example, the page blocked automated access). The team must open it once before submission.

Chapters 1 and 2 cite sources by their APA author-date form. The ID column (S01, S02, …) is only for this matrix.
